# Explain-It-Back Evaluator

A small tool that helps a beginner learn a programming concept by explaining it in their own words. The student picks a concept (variable, loop, function, list), writes an explanation, and gets feedback on which key points they covered and which are missing. They can then revise and be graded again, and the tool says what improved.

## How to run
Open the notebook in Google Colab, add a Gemini API key as a Colab secret named `GEMINI_API_KEY`, then run Cell 1, Cell 2 and the app cell. The key is not stored in this repository.

## Design decision
The key points for each concept are written by me, not generated by the AI, so the AI cannot invent or drift the grading rubric. The AI only judges the student's text against my list.

## What I tested (by hand, rough check, not a formal benchmark)
- 8 test answers: 8 matched the label I expected (good, partial or wrong).
- Consistency check, run twice: in the first run one input varied (during quota errors in the log), and in the second run all inputs were consistent. Grading is not perfectly stable.
- In the live app I also tried a wrong "variable" answer and a wrong "loop" answer. Both were caught with "Not quite:", and the revision flow showed the progress.

## Known limits
- Per-point grading can be generous. For example, "a box that holds something" was marked Covered for "stores a value in memory". My tests only check the overall label, not each key point.
- For some wrong answers the follow-up question gives away too much of the missing point.
- The fallback for API failures is built but not stress-tested.
